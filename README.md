# ✨ Overview

**RamayanaVerse** is an interactive educational platform that brings one of the world's greatest epics to life through modern web technologies.

Instead of simply reading stories, users explore a beautifully designed digital universe featuring cinematic storytelling, immersive animations, AI-powered learning, interactive maps, timelines, character encyclopedias, and engaging educational experiences.

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ramayana-verse.git
```

Go into the project

```bash
cd ramayana-verse
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
